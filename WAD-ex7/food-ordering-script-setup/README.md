# Food Ordering Application

Built using Vue 3, Vue Router, nested routing, Pinia, and Vite.

## Run

```bash
npm install
npm run dev
```

## Main Features

- Vue Router navigation
- Nested routing
- Pinia cart management
- Add, remove, and update food quantities
- Total bill calculation
- Place order message
